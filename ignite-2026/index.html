Microsoft Ignite 2026 결과 정리 — GA·로드맵 중심

11월 17~20일 Ignite에서 발표된 내용 중 Power Platform · Copilot · Foundry · Agent 365 · FinOps · AI 거버넌스 관점에서 챙겨볼 항목만 추렸습니다. 이번 Ignite의 한 줄 요약은 “에이전트를 만드는 단계에서 운영·통제하는 단계로”입니다. 같은 실행 엔진(Copilot harness)이 여러 제품으로 퍼지고, 앱 호스팅(CMR)·비용(Agent 365)·ID(Entra)가 GA 또는 운영 수준으로 올라왔습니다.

GA정식 출시프리뷰퍼블릭 프리뷰FrontierFrontier 프로그램 전용비공개 프리뷰비공개 프리뷰예정날짜가 잡힌 예정일부 GA세부 기능별 상이발표상태 미기재·출처 간 상이

1. 꼭 봐야 할 7가지

1

Copilot Managed Runtime · Copilot Studio 앱 작성

GA

Cowork·Code·Copilot Studio·VS Code 등 어디서 만든 앱이든 MS가 운영하는 테넌트 안 런타임에 올려 Entra 로그인·거버넌스 커넥터·Git 버전관리·M365 관리센터 인벤토리로 관리합니다.

실무 포인트: Power Apps 외에 코드 기반 업무앱을 '관리되는 앱'으로 제안할 수 있는 길이 열렸습니다. Fabric 백엔드(DB·스토리지)는 Frontier 프리뷰, Learn의 앱 작성 문서는 아직 프리뷰 표기입니다.

2

Microsoft Copilot harness (전사 공통 하네스)

GA · Copilot Studio프리뷰 · Foundry

GitHub가 만든 에이전트 실행 엔진(옛 이름 GitHub Copilot harness)을 Copilot Studio·Copilot Code·GitHub Copilot·Foundry가 함께 씁니다. MS 내부 평가에서 Standard 대비 과제 통과율 +10.8~22.1%p, 입력 처리 비용 15~21% 절감.

실무 포인트: 신규 에이전트는 이 하네스가 기본 선택지입니다. 기존 Standard 에이전트를 옮기는 업그레이드 기능(프리뷰)으로 품질·크레딧을 비교해 볼 만합니다. 단, 과금 방식이 달라 사내 라이선스 사용자용 에이전트는 비용이 새로 생길 수 있습니다.

3

새 Copilot 앱: Home · Office in Copilot · Code

GA · Home·Office예정 · Code 12월

Chat과 Cowork를 한 화면(Home)으로 합쳤고, Word·Excel·PowerPoint를 Copilot 앱 안에서 바로 작성합니다(구독에 포함). Copilot Code는 자연어로 대시보드·앱을 만드는 기능으로 수주 내 GA.

실무 포인트: Cowork에서 만든 앱도 GA. 사용자 교육·도입 가이드를 '하나의 Copilot' 기준으로 다시 정리할 시점입니다.

4

Agent 365: 비용·가치·위험을 한 곳에서

발표 · 비용 관리Frontier · Business Analytics프리뷰 · 위험·타사 연동

누적 등록 에이전트 5,000만+. 사용자·서비스·에이전트·모델별 AI 지출과 한도·알림(비용 관리), 지출 대비 성과(Business Analytics), Salesforce·Google·OpenAI 등 타사 에이전트에 Entra Agent ID 부여, 에이전트별 위험 점수.

실무 포인트: 고객사 'AI 비용 통제' 질문에 답할 수 있는 공식 도구가 생겼습니다. FinOps·거버넌스 컨설팅 제안의 근거로 활용.

5

Work IQ를 에이전트 도구로

GA · Copilot Studio·Foundry프리뷰 · 행동 정책

메일·회의·파일·채팅 맥락을 MCP·REST·A2A로 에이전트에 제공(GA). 테넌트 전체·에이전트별 '무엇을 해도 되는지' 정책과 관리자 승인은 프리뷰. Work·Fabric·Foundry·Web IQ를 묶은 Microsoft IQ도 발표.

실무 포인트: 새 Copilot harness 에이전트에는 Work IQ가 기본 탑재(쓰기 포함, 권한 범위 내). 쓰기 권한 정책을 먼저 설계해야 합니다.

6

Foundry: 운영 단계 기능 대거 GA

GA

실시간 음성 에이전트, 컴퓨터 사용·브라우저 자동화, 호스트형 에이전트 외부 통신(egress) 허용목록, 개발도구 일괄 설치(Dev Pack), 프로덕션 Insights, 경량 판단 모델 Microsoft-Decision-1.1.

실무 포인트: PoC를 넘어 운영·보안 요건(통신 통제, 장애 복구, 모니터링)을 갖춘 프로코드 에이전트 제안이 가능해졌습니다.

7

거버넌스 일정 주의: DLP for Copilot은 아직

GA · Entra 수명주기예정 · DLP 2027-01

Entra 에이전트 ID 자동 수명주기 관리(미사용 시 알림→비활성→삭제)는 GA 발표(Learn은 아직 프리뷰 표기). 라벨 없는 민감 파일까지 Copilot 참조를 막는 Purview DLP는 2027년 1월 퍼블릭 프리뷰 예정.

실무 포인트: 고객 제안서에 'DLP로 차단 가능'이라고 쓰기 전에 일정 확인이 필요합니다.
