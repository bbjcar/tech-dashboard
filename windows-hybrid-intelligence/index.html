1. 한 문장 요약 · 3가지 축

Windows를 에이전트가 로컬에서 돌 수 있으면 로컬에서, 필요하면 클라우드로 가는 “하이브리드 인텔리전스” 플랫폼으로 만들고, 그 전제 조건인 에이전트 보안(MXC)과 로컬 AI를 돌릴 하드웨어(RTX Spark)를 함께 내놓은 발표입니다.

① 에이전트 보안

격리(Containment) · 에이전트 ID(Identity) · 관리(Manageability). MXC 정식 출시, Agent 365·Intune과 연동

② 하이브리드 인텔리전스

로컬 모델 + 지능형 라우팅 + 런타임(Windows ML). 작업마다 로컬/클라우드를 골라 토큰 비용 절감

③ 새 PC 라인업

Copilot+ PC → RTX Spark 기반 Builder PC → DGX Station for Windows까지

3. 보안: Microsoft Execution Containers(MXC) GA

항목내용
왜 필요한가에이전트는 일반 앱과 달리 24시간 돌면서 도구를 쓰고, 코드를 쓰고, 파일에 접근합니다. 프롬프트와 도구 호출마다 필요한 격리 수준이 달라서 기존 샌드박스로는 부족하다는 것이 Microsoft의 설명입니다.
3가지 기본 기능
  • Containment: 에이전트가 접근할 수 있는 파일·네트워크를 정책으로 정하고 실행 중에 강제
  • Identity: 어떤 에이전트가 한 일인지 사용자 활동과 구분
  • Manageability: Agent 365, Intune으로 정책 설정·위험 모니터링 (대규모 거버넌스에는 추가 서비스가 필요할 수 있음)
격리 단계프로세스 격리 → 세션 격리 → WSLc → 가상 머신 → Windows 365 for Agents. MXC 자체는 다른 OS에서도 동작하지만 Windows에서 선택지가 가장 많습니다.
지원 에이전트지원 중: OpenAI Codex, GitHub Copilot, OpenClaw, Replit, LM Studio, NVIDIA OpenShell, Unsloth AI
지원 예정: Claude Code, Box, Egnyte, Hermes Agent, Manus, Perplexity, Raycast 등. Meta의 Muse도 MXC를 통합한 Windows 네이티브 앱으로 출시 예정

4. 로컬 모델 · 라우팅 · Windows ML

구분내용상태
MAI Code 1.1 Flash (로컬판)Microsoft의 코딩 모델. 전체 137B·활성 6.8B 파라미터(MoE). 약 3비트(혼합 정밀도 평균 약 3.3비트)로 양자화해 크기를 약 80% 줄인 53GB, 256K 컨텍스트 지원(256K에서 최대 메모리 약 75.5GB). SWE-Bench Verified는 클라우드 72.6%, 로컬 70.8%(Microsoft 측정)실험 배포
NVIDIA Nemotron (예정 모델)70B 이상 모델을 2비트로 양자화해 약 20GB 메모리로 실행예정
DeepSeek V4 Flash284B 파라미터 모델을 RTX Spark에서 로컬 실행. 보도 기준 메모리 60GB 이상 장비에서 동작예정
GitHub HydraFusion작업마다 알맞은 모델로 보내는 GitHub의 라우팅. Windows에서는 로컬 모델까지 후보로 사용. GitHub Copilot 앱·CLI·VS Code에 실험 프리뷰. 자동 라우팅 말고 로컬 모델을 직접 고를 수도 있음프리뷰
Windows ML + llama.cppWindows ML(GPU·NPU·CPU 공통 로컬 추론 런타임)에 llama.cpp 통합 → GGUF 모델을 그대로 실행. Text Generation API가 ONNX·GGUF를 함께 받고, OpenAI 호환 엔드포인트도 제공해 기존 OpenAI SDK로 시험 가능실험

포인트: 로컬 실행의 장점은 지연 시간 감소 · 데이터가 기기에 머묾 · 토큰당 클라우드 비용 없음입니다. 단, 큰 모델은 메모리가 관건입니다. MAI Code 1.1 Flash를 256K 컨텍스트로 쓰려면 사실상 128GB 메모리 구성이 필요합니다.

8. 실무 포인트 · 교육 Q&A

관점정리
거버넌스PC 에이전트 관리는 MXC(격리) + Entra 에이전트 ID + Agent 365·Intune(정책·관찰) 조합으로 설명하면 됩니다.
비용로컬 모델은 토큰 비용이 없는 대신 하드웨어 비용이 듭니다. 클라우드 격리 단계인 Windows 365 for Agents는 Ignite 2026에서 Copilot Credits 과금 대상으로 발표됐습니다.
도입 조건Copilot 로컬 기능은 Copilot+ PC 대상이고, 큰 로컬 모델은 RTX Spark급 메모리가 필요합니다. 기존 PC로 바로 되는 기능이 아님을 먼저 안내하세요.

Q. Autopilot은 클라우드 영역만 담당해서 로컬 PC에서는 에이전트를 쓸 수 없다. 로컬 PC 쪽은 어떤 서비스가 맡나?

A. Windows의 Hybrid Intelligence (Cloud + Local AI)가 그 역할을 맡습니다. 발표 기준으로 Autopilot에도 로컬 컨텍스트·로컬 작업·로컬 모델이 결합될 예정이라, “클라우드 에이전트 + PC 쪽 실행 능력”으로 이어지는 구조입니다. 기술적 핵심은 OS 수준 격리(MXC)와 로컬 AI입니다.

Ignite 2026 후속: MXC에 새 격리 기능이 추가됐고, Windows 365 for Agents가 Copilot Credits 과금 대상이 됐습니다. 자세한 내용은 Ignite 2026 결과 정리를 참고하세요. Azure Landing Zone 용어 정리는 기술노트로 옮겼습니다.
