1. 한눈에 보기: 비용을 내는 3가지 방식

Microsoft는 AI 업무를 "일상 AI"(라이선스)와 "고급 AI"(사용량 과금)로 나눕니다. 여기에 라이선스 없는 사용자용 종량제가 더해져 3가지 방식이 됩니다.

Microsoft 365 Copilot 라이선스

2. 라이선스가 있으면 추가 요금 없이 쓰는 범위

Microsoft 365 Copilot 라이선스를 받은 사용자가 본인 계정으로 Microsoft 365 안에서 쓰는 경우입니다.

항목추가 요금조건·비고
Copilot Chat (웹 + 업무 데이터)없음메일·파일·회의 등 업무 데이터 기반 대화 포함
Word·Excel·PowerPoint·Outlook·Teams의 Copilot없음앱에 내장된 Copilot 기능
Auto 모드와 모델 선택없음GPT 5.6·Sonnet 같은 모델은 공정 사용 범위 안에서 포함. Opus 같은 일부 모델은 한도 안에서만 포함
선언형 에이전트
Agent Builder, Agents Toolkit		없음SharePoint·Copilot 커넥터 데이터를 쓰는 에이전트도 포함
Copilot Studio 에이전트 (표준 하네스)없음Teams·Copilot Chat 등 Microsoft 365 채널에서, 라이선스 사용자가 본인 계정으로 인증해 사용할 때. 생성형 답변, 테넌트 그래프 그라운딩, 에이전트 작업 모두 포함 (공정 사용 한도 적용)
에이전트가 호출하는 에이전트 흐름없음"When an agent calls the flow" 트리거로, 라이선스 사용자와 대화 중에 실행될 때만
Copilot Studio에서 에이전트 만들기·게시없음Microsoft 365 Copilot 라이선스가 있으면 Copilot Studio에서 에이전트를 만들고 게시할 수 있음
💡 기억할 한 줄: 라이선스 사용자 + Microsoft 365 채널 + 표준 하네스 에이전트 조합이면 추가 요금이 없습니다. 이 중 하나라도 벗어나면 크레딧이 듭니다.

3. 라이선스가 있어도 추가 비용이 드는 경우

아래 항목은 모두 사용량 과금입니다. 라이선스는 일부 기능의 "입장권"일 뿐이고, 실제 사용량은 Copilot Credits로 따로 냅니다. 관리자가 결제 수단과 지출 정책을 설정해야 사용자가 쓸 수 있습니다.

Copilot 라이선스 필요 라이선스가 있어야 사용 가능 · 무관 라이선스 없이도 사용 가능결제 수단 크레딧 미리 산 Copilot Credits (용량 팩·P3) · 종량제 Azure 구독으로 쓴 만큼 후불 · 없음 추가 결제 없음두 결제 수단이 함께 표시된 항목은 어느 쪽이든 고를 수 있고, 함께 쓰면 크레딧을 먼저 쓰고 남는 사용량을 종량제로 넘길 수 있습니다.
기능Copilot 라이선스결제 수단비고
Copilot Cowork필요크레딧종량제여러 단계에 걸친 장시간 작업 위임. 관리자가 지출 정책에 사용자와 Cowork를 넣어야 사용 가능

SharePoint·OneDrive 고급 작업필요크레딧종량제SharePoint의 새 에이전트형 기능
최신 프런티어 모델 · 사용 한도 초과필요크레딧종량제예: Astra, Fable. 라이선스 한도에 닿으면 크레딧으로 계속하거나 Auto로 전환 (한도 알림은 출시 예정)
Copilot Studio – Microsoft Copilot 하네스 에이전트무관크레딧종량제만들기·테스트·평가·실행 모두 과금. 라이선스 사용자가 써도 보전되지 않음
Copilot Studio – 컴퓨터 사용(CUA)무관크레딧종량제라이선스 포함 대상 아님
Copilot Studio – Microsoft 365 밖 채널무관크레딧종량제예: 고객용 웹사이트 챗봇. 사용자의 라이선스와 상관없이 과금
자율 실행·다른 트리거의 에이전트 흐름무관크레딧종량제예약 실행, 이벤트 트리거 등. 100개 작업당 13크레딧
Work IQ API무관크레딧종량제Copilot 라이선스와 별개 서비스. 라이선스 사용자도 사용자 지정·타사 에이전트에서 호출하면 과금
Copilot Managed Runtime (CMR) 앱무관크레딧종량제앱을 만들 때와 실행할 때 모두 크레딧 소모. 실행 비용은 관리 센터에서 따로 정책 설정

이 밖에도 Teams Phone Agent, Copilot Agents with Work IQ, Clipchamp 동영상 생성, Teams 통역, Windows 365 for Agents 등이 사용량 과금 대상이고, 대상 서비스는 계속 늘어납니다. 라이선스 "필요"는 Microsoft 문서에 Copilot 라이선스가 필요하다고 명시된 항목입니다. Copilot Studio 항목은 Copilot 라이선스 대신 Copilot Studio 사용자 라이선스(무료 추가 기능)를 할당하거나 Power Platform 관리 센터에서 사용을 허용하면 만들 수 있고, 크레딧이나 종량제 중 하나만 준비되면 됩니다.

5. 고객 시나리오별 정리

매일 아침 자동으로 도는 에이전트 흐름무관크레딧종량제사람이 대화 중에 부른 게 아니라 예약 트리거라 과금
CMR(Managed Apps)로 만든 사내 앱 운영무관크레딧종량제개발과 실행 모두 크레딧 소모
사내 시스템에서 Work IQ API 호출무관크레딧종량제호출량만큼 과금
Agent 365 Business Analytics로 AI 비용 대시보드 보기필요
